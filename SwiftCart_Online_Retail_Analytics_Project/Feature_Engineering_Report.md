# SwiftCart Feature Engineering Report

| Feature | Business purpose |
|---|---|
| Unit_Price | Compare price per unit when Qty differs |
| Order_Value | Measure total value of an order |
| Order_Item_Count | Measure number of line items in an order |
| Order_Qty | Measure total units in an order |
| Customer_Order_Count | Measure repeat-purchase intensity |
| Month_Num | Support chronological monthly analysis |

These features add price-, order-, customer-, basket-, and time-level views while retaining the original measures.
